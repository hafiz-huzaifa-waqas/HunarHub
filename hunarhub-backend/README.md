# HunarHub

HunarHub is an agent-assisted marketplace that connects home-based women entrepreneurs with customers.

Many home-based artisans (stitching, baking, handicrafts, henna, tutoring) are not comfortable using technology. In HunarHub, a trained field Agent registers the seller, lists her products, and handles orders on her behalf. Customers browse, order, and review. The system calculates the Agent's commission automatically. Admins oversee everything.

## Users

- **Agent** — registers sellers, manages listings, updates order status, earns commission
- **Customer** — browses, orders, tracks orders, reviews sellers, reports problems
- **Admin** — verifies sellers, sets commission rates, records agent payouts, resolves reports

Sellers do not log in. They are represented by their assigned Agent.

## Features

- Seller registration and admin verification
- Product listing and browsing by category
- Order placement with stock management
- Order status tracking with full history
- Automatic commission calculation on delivery
- Agent earnings and admin payouts
- Ratings, reviews, and problem reports
- Admin dashboard for platform monitoring

## Tech Stack

React, Node.js, Express, PostgreSQL
